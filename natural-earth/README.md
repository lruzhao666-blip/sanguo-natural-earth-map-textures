# Natural Earth 亚洲底图素材

本目录只放 Natural Earth 陆地轮廓和灰度地形晕渲，不混入三国区域数据。不含现代国界、道路、地名或游戏原版素材。

## 范围与文件

统一裁剪范围：**东经 15°—180°、南纬 15°—北纬 82°**（`[15, -15, 180, 82]`）。采用宽裕的亚洲工作矩形，不是按洲界切割；因此包含部分欧洲、东北非、澳大利亚北部及附近海域，给后续地图扩展留余量。东界到 180°，不跨日期变更线；北极 82° 以北、亚洲日期变更线另一侧及澳大利亚南部不在本包内。

| 文件 | 用途 |
|---|---|
| `ne_10m_land_asia.geojson` | Natural Earth 1:10,000,000 Land 裁剪，WGS84 经纬度 GeoJSON；保留裁剪后边界细节，未简化。 |
| `SR_HR_asia.png` | Shaded Relief Basic 裁剪，9900×5820、8-bit 灰度，保持原始 1 角分/像素，不缩放或调色。 |
| `SR_HR_asia.pgw` / `SR_HR_asia.prj` | PNG 的世界文件和 WGS84 投影说明；不是 PNG 内嵌的地理信息。 |
| `metadata.json` | 范围、版本、原始下载包摘要、素材摘要、像素转换方式与限制。 |
| `verify.py` | 仅使用 Python 标准库的资产自检；运行 `python natural-earth/verify.py`。 |

## 如何定位

GeoJSON 坐标顺序为 `[经度, 纬度]`（RFC 7946），不是画布像素。晕渲图为北向上、等经纬网格，无旋转，覆盖同一矩形。

以 PNG 左上角为原点，像素边界坐标与经纬度的关系为：

```text
x = (longitude - 15) * 60
y = (82 - latitude) * 60
```

上式用于连续的像素边界坐标；`pgw` 的六个参数则采用像素中心约定。图像右/下边缘分别为 x=9900、y=5820。不要把经纬度跨度误当成地表等距距离。

现有 `gpkg_all_data.json` 的 2000×1600 多边形是画布坐标，不能把整张亚洲图直接拉伸到该画布。需要先核实原地图的投影和坐标映射，再裁取/投影底图并核对海岸线。本次仅入库素材，**尚未完成与三国区域的配准，也未修改任何区域边界**。

## 视觉用途

建议从海洋底色、浅色陆地开始，叠加低饱和势力色，再用低强度灰度晕渲混合出地形明暗，最后绘制边界和地名。应在渲染层限制晕渲只影响陆地、确保势力色和地名可读；本 PNG 保留官方原始灰度及平坦水域，不是已去海洋的透明纹理。此方案只是策略地图的视觉基础，不保证复刻《文明时代2》的原版效果。
