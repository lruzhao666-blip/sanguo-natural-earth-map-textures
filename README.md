# 三国策略地图 · AI 制作入口

目标：用三国区域数据制作类似《文明时代2》的地图，包括深色海洋、地形明暗、势力色、细边界、地名与选中高亮。

**模型默认只读本页和 `coordinates.json`。** 编写代码加载下表数据；用程序解析完整坐标，避免把大型 JSON、所有分片或史料全文塞进对话。

| 文件 | 用途 | 加载方式 |
|---|---|---|
| `map.json` | 148 个区域的边界、名称、州、标注位置 | 程序加载 |
| `scenario.json` | 190 年 1 月剧本；40 个势力、HEX 颜色、148 区域归属 | 程序加载 |
| `coordinates.json` | 2000×1600 画布、经纬度换算、图片位置 | 模型读取 |
| `assets/land.geojson` | 画布范围的轻量陆地轮廓，含岛屿和孔洞 | 程序加载 |
| `assets/relief.webp` | 默认晕渲图；2880×1620，约 297 KB | 图片加载 |

## 字段与关联

- `map.json` 顶层：`canvas_size`、`bounds_wgs84`、`provinces`。每个区域：`id,name,state,center_x,center_y,polygon`。
- `polygon` 是闭合的画布 `[x,y]`；原点左上，x 向右、y 向下。`center_x/center_y` 用于放标签，不保证是精确郡治。
- `scenario.json`：`factions[]` 含 `id,name,start_city_id,color`；`ownership[区域id]` 给出势力 ID。值为 `null` 表示地方官府/待考，有居民和守军，不能当空地。
- 颜色直接用 `factions[].color`；用 `ownership[province.id]` 关联区域。基础地图约为 262 年分区，190 年归属包含游戏化安排。
- `land.geojson` 为 WGS84 `[经度,纬度]`；转换到画布后绘制。区域边界已经是画布坐标，不要再转换一次。

## 网页尺寸与缩放

目标视口为 **1920×1080 及以上**，容器随浏览器全屏变化。逻辑地图保持 2000×1600；**初始视图完整保留地图上下范围**，按高度等比显示，左右补足地理底图。禁止用 `cover` 放大后裁掉上下，也不要把区域强拉成 16:9。初始相机：`scale = viewportHeight / 1600`，`offsetX = (viewportWidth - 2000 * scale) / 2`，`offsetY = 0`。Canvas 绘制缓冲区按实际视口和 `devicePixelRatio` 设置，边界与文字按当前缩放重绘。

## 叠加顺序

海洋底色 → 陆地遮罩 → 陆地内的低强度灰度晕渲 → 半透明势力色 → 区域细边界 → 地名与选中高亮。

默认晕渲图完整保留原画布南北范围，并向左右扩展为宽屏背景。按 `coordinates.json` 的 `draw_canvas_rect` 绘制（x 可为负数）；不要把它压进原来的 2000×1600 矩形，也不要将背景裁在区域画布边缘。图像有损压缩，深度放大时会变软；代码加载它，不要默认下载 17 MB 的源 PNG。

**已配准（声明范围内的数学换算）**：坐标方向、范围、世界文件和往返换算通过；尚未通过独立地理控制点验证，不能把数值误差当实测定位精度。
